BLOG THUMBNAILS GO IN THIS FOLDER
=================================

Each article expects one cover image here, named exactly:

  post-1-thumb.jpg   (The Science of Fat Loss)
  post-2-thumb.jpg   (Building Muscle Naturally)
  post-3-thumb.jpg   (PCOS and Fitness)

Recommended size: 1200 x 675 pixels (16:9), JPG, under ~300 KB.
Free tool to resize/crop: https://squoosh.app

Until you add them, the site shows a clean red dumbbell placeholder
instead — nothing breaks. When you add post-4, name its image
post-4-thumb.jpg and reference it in blogs/data.json.
